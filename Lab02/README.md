# Лабораторна робота №2


Варіант: N = 18 ($K = 12$, $a = 0$, $b = 2$, $c = 3$)

Перестановка (Завд. 4): Від'ємні та нулі переносимо на початок, решту — в кінець.

Матриця (Завд. 5): Розмір 3 × 6 (значення від 1 до 4).
